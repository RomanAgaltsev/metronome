# Security Policy

## Supported Versions

`metronome` is pre-1.0. Only the latest `v0.x` release line receives security fixes.

| Version       | Supported |
| ------------- | --------- |
| latest `v0.x` | ✅        |
| older         | ❌        |

## Reporting a Vulnerability

Please report security issues privately by email to roman-agalcev@yandex.ru.
Do not open public issues for security reports.

We aim to acknowledge reports within 5 business days.
